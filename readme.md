# LinguQuest (언어 퀘스트) 🚀

한국인 사용자를 위한 맞춤형 한국어, 영어(IH), 스페인어(IM1) 단어 암기 게임입니다.

## 🌟 주요 특징
- **게이미피케이션**: 경험치(XP), 레벨, 스트릭 시스템을 통해 단어 공부를 게임처럼 즐길 수 있습니다.
- **자동 스케줄링**:
    - **평일 (월~금)**: 새로운 단어 5개를 학습하고 퀴즈를 풉니다.
    - **주말 (토~일)**: 한 주간 배운 내용을 복습하는 '복습 퀘스트'가 활성화됩니다.
- **프리미엄 디자인**: 다크 모드 기반의 세련된 UI와 부드러운 애니메이션을 제공합니다.
- **데이터 보존**: 별도의 로그인 없이 브라우저의 로컬 스토리지를 통해 진행 상황이 저장됩니다.

## 🛠 사용 방법
1. `index.html` 파일을 크롬이나 웨일 등 최신 브라우저로 엽니다.
2. 매일 세 가지 언어의 퀘스트를 완료하여 스트릭을 유지하세요!
3. 레벨을 올려 최고의 언어 마스터가 되어보세요.

## 📝 커스터마이징
`app.js` 파일 상단의 `wordDB` 객체에 본인이 외우고 싶은 단어를 추가하여 나만의 단어장을 만들 수 있습니다.
